# Orientações do projeto

Preservar a estrutura funcional, dados públicos autorizados, nomenclatura LCR, testes, revisão por PR e decisões rastreáveis. Não publicar documentos de terceiros nem segredos. Consultar as normas canônicas autorizadas do LCR antes de alterações estruturais. Executar npm run validate em code/ antes de propor merge.
