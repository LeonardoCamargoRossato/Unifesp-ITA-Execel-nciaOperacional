# Excelência Operacional em Tecnologias Quânticas

Ambiente acadêmico pessoal de pesquisa, no contexto UNIFESP / ITA. Não é um site institucional.

## Desenvolvimento

```sh
cd code
npm ci
npm run dev
npm run validate
```

React, TypeScript e Vite; publicação estática, sem backend. Veja [documentação](documentation/README.md).
