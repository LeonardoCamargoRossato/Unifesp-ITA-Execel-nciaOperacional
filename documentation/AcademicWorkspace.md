# Academic Workspace V1

Shell e componentes reutilizáveis em components; módulos de conteúdo em content; páginas espelham a navegação; contrato bibliográfico em lib. Páginas importadas sob demanda. Nenhum arquivo acadêmico original integra o build. Links de acervo exigem as permissões originais; não divulgar URLs individuais de materiais não compartilhados. Os eixos são propostas, não resultados. Inventário vazio até integração aprovada.

Quality Gate: lint dos scripts, typecheck TS, testes Node, PSM, build e auditoria de dependências. Testes externos e navegador devem ser validados separadamente quando não executados. Sem chamadas externas automáticas; único host de produção previsto: GitHub Pages. Orçamento proposto: build JS/CSS abaixo de 1 MiB; sem recursos pagos. Publicação via Actions separada do PR; não alterar permissões do Drive. Backup central sinalizado pelo marcador LCR_START, execução não presumida.
